# MIT 8103 Advanced Database Systems Portfolio
**Case study:** University Student Management and Course Registration System

This repository contains practical scripts and documentation for five portfolio activities.

## Contents
- `portfolio-1-database-design/`: schema, sample data, ER model notes
- `portfolio-2-query-optimisation/`: SQL queries, indexes, query-plan instruction
- `portfolio-3-transactions-concurrency/`: transaction/rollback and concurrency notes
- `portfolio-4-nosql/`: MongoDB document example
- `portfolio-5-distributed-cloud/`: distributed/cloud architecture discussion
- `final-documentation/`: summary report, reflection, AI use declaration

## How to run
The relational scripts are SQLite-compatible. Open them in a SQLite-capable browser editor or local SQLite environment. Run the schema first, then sample data, then queries. MongoDB commands require a MongoDB environment (mongosh/Atlas) to execute.

## Evidence checklist
Capture your own screenshots of successful execution and outputs. Do not label code examples or proposed architecture as tested/live unless you actually ran/configured them.
